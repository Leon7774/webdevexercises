React First Steps

React is a popular JavaScript library for building user interfaces using "Components".

Exercise: Move to the React Template

Notice how similar the React code is to HTML! Instead of writing more code in this repository, let's move to a real React project setup.

  1. Clone the React Tailwind Template to your computer:
    git clone https://github.com/Leon7774/ReactTailwindTemplate.git
  2. Navigate into the directory: cd ReactTailwindTemplate
  3. Run npm install to install dependencies.
  4. Start the dev server with npm run dev.
  5. Open the project in your editor. Find the exercise 7 component, and try adding a second button that resets the count to 0!
